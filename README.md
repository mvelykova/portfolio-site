## Інформація про проєкт

- Університет: КПІ ім. Ігоря Сікорського
- Курс: 2
- Варіант: 2
- Назва проєкту: portfolio-site

## Мета проєкту

Створення клієнтського вебзастосунку для
представлення портфоліо фотографа або дизайнера.

## Технології

- HTML5
- CSS3
- JavaScript

## Структура проєкту

- index.html — головна сторінка
- css/style.css — стилі
- js/app.js — JavaScript
- assets/img — зображення
